Your Brand POS

Technical requirements

What a shop needs to run the system. Everything runs locally on the shop's network; the internet is needed only for card payments, updates and off-site backups.

Optional  Planned

Server (in the shop)

ComputerMini PC, Raspberry Pi 4/5 (4 GB) or any Linux/macOS computer, left on during trading
SoftwarePython 3.9 or newer, OpenSSL. No other packages or database server
Storage1 GB free is ample; all data in one SQLite file
NetworkWired or Wi-Fi on the shop network, with a fixed IP address (DHCP reservation)
PowerUPS recommended Optional

Network and security

ProtocolHTTPS only, TLS 1.2+, on port 443 (or 8443)
CertificateSelf-signed for trial; trusted certificate via own domain and reverse proxy (e.g. Caddy) for production
Wi-FiCovering counter and stock areas; phones join the same network
LoginsOwner and cashier roles, PIN login, 12-hour sessions, lockout after repeated wrong PINs
Remote accessSecure tunnel (e.g. Tailscale) Optional

Register and phones

RegisterLaptop, PC or tablet with a current Chrome, Edge, Safari or Firefox; 10" screen or larger
PhonesiPhone or Android with a current browser and rear camera, for scanning, receiving and stocktake
NFC writingAndroid phone with NFC, Chrome browser Planned
InstallNothing to install; pages can be added to the home screen

Payments

CashBuilt in, with Australian 5c rounding and change calculation
CardShop's own Square account and reader, used alongside the register
Card dataNever entered into or stored by the POS
Integrated readerStripe Terminal or Square Terminal Planned

Scanning hardware

Bench scanner2D (QR-capable) presentation scanner, USB or Bluetooth, keyboard (HID) mode with Enter suffix
HandheldCordless 2D scanner, keyboard mode, for large items Optional
Overhead camera1080p autofocus USB webcam on an arm, even LED lighting Optional
NFC pad13.56 MHz ISO 14443A reader, NTAG21x, USB keyboard mode (UID output) Planned
NFC writerPC/SC USB reader/writer (ACR122U class) as an alternative to Android Planned

Printing and labels

Label printerDesktop direct thermal, 2"–4" (e.g. TSC DA/TE series), taking third-party rolls; OS driver installed
Tag sizes50×25, 50×30, 40×30, 57×32, 62×29 mm presets, any custom size, or A4 21-up sheets
Tag contentQR code: SKU|VENDOR|PRICE, or a link to the stocktake screen
NFC labelsDirect thermal paper labels with NTAG213 inlay, matching printer core size Planned
Receipts58, 62 or 80 mm thermal printer, or on screen Optional

Australian compliance

GST10%, prices GST-inclusive; GST-free items supported
ReceiptsTax invoice format once the shop's ABN is entered
ReportingGST collected per period to support BAS
Time zonesAll Australian states and territories

Data and backup

StorageSingle SQLite database file on the shop's computer
BackupOne-click download from Settings; automatic off-site backup Planned
AuditRefunds, price changes, stock adjustments and settings changes logged with user and time
CapacitySized for a single shop: hundreds of products, multiple registers and phones
Minimum to start trading: one computer on the shop network, one register device with a browser, a QR-capable scanner or phone camera, a direct thermal label printer, and a card reader from the shop's own provider.
